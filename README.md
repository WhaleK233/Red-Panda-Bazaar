# Red Panda Bazaar
This is a new expansion mod for Stardew Valley which adds 3 new NPCs, some locations, a few shops and a new festival!

## Install
1. [Install the latest version of SMAPI](https://smapi.io/).
2. [Install Content Patcher](https://www.nexusmods.com/stardewvalley/mods/1915).
3. Install [this mod from Nexus mods](https://www.nexusmods.com/stardewvalley/mods/30982).
4. Run the game using SMAPI.
