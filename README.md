## Installation

1. Download and install [SMAPI](https://smapi.io/).
2. Download the latest release of Red Panda Bazaar Code from [Nexus](https://www.nexusmods.com/stardewvalley/mods/???).
3. Extract the downloaded zip file into your `Mods` folder in the Stardew Valley directory.
4. Launch Stardew Valley using SMAPI.

## Configuration

You can configure the mod settings using the [Generic Mod Config Menu](https://www.nexusmods.com/stardewvalley/mods/5098).

## Compatibility

This mod is compatible with Stardew Valley 1.6+ and SMAPI 4.0.0+.
